## Overview
A lightweight, autonomous CLI AI Agent powered by Anthropic's Claude 4.5 Haiku via the OpenRouter API. It utilizes a continuous execution loop to intelligently process user prompts, interact with the local filesystem, and execute terminal commands natively.

## How to run

1. Ensure you have `uv` installed locally.
2. Run `./your_program.sh` to run your program, which is implemented in
   `app/main.py`.
3. Run `codecrafters submit` to submit your solution to CodeCrafters. Test
   output will be streamed to your terminal.
